[This project](https://github.com/andrewjtdunn/math-ml-project) builds a machine learning classifier from scratch using nothing but NumPy — no scikit-learn, no PyTorch, no autograd.

Writing the forward pass, the loss, and the gradients by hand is the fastest way to stop treating a model as a black box. Everything the libraries normally hide has to be derived and implemented explicitly.
